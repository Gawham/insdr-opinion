# Opinion Backend

This backend provides a single endpoint to submit "Thinking Optimization" audit requests. It handles file uploads, hashes the content, stores the file in Google Cloud Storage, and records the request on the Etherlink Shadownet blockchain.

## Base URL
- Local: `http://localhost:3000`

## Endpoints

### 1. Submit Audit Request
Submit a context file and LLM output for audit.

- **URL**: `/audit-request`
- **Method**: `POST`
- **Content-Type**: `multipart/form-data`

#### Request Body (form-data)
| Key | Type | Description |
| :--- | :--- | :--- |
| `contextFile` | File | The source file (context) used by the LLM. Max size depends on server config (default unbounded). |
| `llmOutput` | String | The text output generated by the LLM that needs verification. |
| `modelId` | String | Identifier for the model used (e.g., "gemini-1.5-pro"). |

#### Example Request (cURL)

```bash
curl -X POST http://localhost:3000/audit-request \
  -F "contextFile=@/path/to/your/document.pdf" \
  -F "llmOutput=The summary of the document is..." \
  -F "modelId=gpt-4-turbo"
```

#### Success Response (200 OK)

```json
{
  "message": "Audit Request Submitted",
  "transactionHash": "0x123abc...",
  "gcsUrl": "https://storage.googleapis.com/brainjs-brain/verify/1715623456789-document.pdf",
  "status": "Consensus Pending"
}
```

- **transactionHash**: The hash of the transaction on Etherlink Shadownet. You can find it on the [Explorer](https://shadownet.explorer.etherlink.com).
- **gcsUrl**: The direct link to the stored file in the `brainjs-brain` bucket (under `verify/` folder).

#### Error Response (500 Internal Server Error)

```json
{
  "error": "Error message details used for debugging"
}
```

## Setup & Running

1.  **Dependencies**:
    ```bash
    npm install
    ```
2.  **Configuration**:
    Ensure `.env` contains:
    -   `PRIVATE_KEY` (Wallet private key)
    -   `GCP_KEYFILE_PATH` (Path to service account JSON)
    -   `GCP_PROJECT_ID`
    -   `BUCKET_NAME`
    -   `CONTRACT_ADDRESS`
3.  **Start Server**:
    ```bash
    node server.js
    ```
